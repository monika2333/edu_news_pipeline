# 控制台亮暗主题

日期：2026-11-11
合入：`7f8548c`（主题功能）、`8d4c6cf`（外观单行与手机端菜单溢出）、`64ca75e`（外观下拉框原生样式），分支 `feat/console-dark-mode` 快进合并。
另有两个提交在评审后被删除：`c502382`、`c88c561`（原生 select 的居中补丁，用户认为改得更差）。

## 背景

控制台只有亮色样式。用户打开操作系统暗色模式后仍看到亮白页面，长时间使用刺眼。需求为：

- 整个控制台统一支持暗色，不只筛选页；
- 管理员和值班编辑都能手动设置；
- 未设置时跟随系统，系统切换实时生效；
- 偏好按浏览器记忆。

## 拍板

- **范围**：登录/注册/改密、用户与排班、系统设置、筛选、汇总审阅、值班、报送存档、值班汇总、`admin_entry`。
- **入口**：账号菜单里的「外观」，一项三档（跟随系统 / 亮色 / 暗色）。原因是管理员与值班编辑所有工作页都有账号菜单，登录/注册/改密没有账号菜单，天然满足「有菜单才有控件」。
- **存储**：只用 `localStorage.console_theme`，值 `system|light|dark`；缺省/非法按 `system`；不建数据库字段、不加 API。
- **形态（2026-11-11 最终）**：单行 `外观 [跟随系统 ▾]`，原生 `<select>`，样式向值班页「历史班次」下拉框看齐（边框、控件底色、常规前景色）；面板宽度与账号菜单触发器一致；外观放在修改密码之前，分割线只留在退出登录之前；选项文字不跟随 hover 变蓝。
- **居中尝试已回退**：只加 `text-align:center` 时原生 select 会在箭头左侧区域居中，整块看起来偏左；改用自绘箭头 + 不对称 padding 后用户认为更差，两个提交被删除。要严格居中只能换自定义下拉，不在原生 select 上继续打补丁。

## 实现

### 首帧与运行时

- `web_templates/_theme_head.html`：同步内联脚本读取 `localStorage` + `matchMedia`，在任何 stylesheet 之前设置 `<html data-theme>` 与 `style.colorScheme`，避免先白后黑；随后以 `defer` 加载 `theme.js`。10 个页面模板都 include。
- `web_static/js/theme.js`：解析/应用主题；点击/下拉 change 持久化；`matchMedia` 变化仅在 `system` 时重解析；`storage` 事件跨标签页同步；只读写 `console_theme`。控件兼容旧的 `[data-theme-option]` 与现在的 `[data-theme-select]`。
- `base.css`：暗色下用 `:where(:root[data-theme="dark"]) :where(input,select,textarea)` 给未显式着色的原生控件兜底（零优先级，亮色零声明）；`html` 补页面底色，暗色无样式页（`admin_entry`）也有正确画布。

### Token

- `variables.css` 是唯一允许出现颜色字面值的文件：`:root` 亮色值逐字等于改造前，`:root[data-theme="dark"]` 同名覆盖，并设置 `color-scheme: light/dark`；共 146 个颜色 token，保留原有 10 个变量名。
- 全部 CSS（26 个文件）的颜色、渐变、阴影、focus ring 迁到 token；`manual_filter/utils.js` 的 toast 按钮颜色改为 `var(--toast-action-color)`；`manual_filter.html` 内联样式改 token。
- 主色填充按钮用新增 `--primary-fill` / `--primary-fill-hover`；暗色 `--primary-color` 是浅蓝，只用于文字/描边。红/绿/黄状态色拆成 `*-text` / `*-bg` / `*-border`。

### 账号菜单

- `_account_menu.html` 中 `外观` 一行：`label` + 原生 `select[id=console-theme-select][data-theme-select]`，三个 option。
- `header.css`：整行按普通菜单项的高度/内边距（`6px 12px`）；`select` 带 `1px var(--border-color)` 边框、`var(--card-bg)` 底、`var(--text-primary)` 字、`option` 同色；`max-width` 足够放「跟随系统」；hover 只改行背景和「外观」标签，不改 select 文字。
- 面板 `width: 100%`（相对 `.account-menu` 触发器）+ `box-sizing: border-box`，实测桌面/手机均为 162.8px 对 162.8px；`min-width: 140px` 兜底极短账号名。

## 已知限制 / 后续

- 预览库没有待处理新闻/班次，筛选/审阅/值班/值班汇总部分截图是空态；筛选决定菜单、评分反馈、原文抽屉、查重弹窗只做了 token/静态契约覆盖，没有真实数据下的暗色截图。
- 原生 `<select>` 的弹出层由浏览器/系统绘制；选项的 `color`/`background` 已显式给 token，常规 Chrome/Edge 跟随主题，个别系统可能不完全一致。
- 核心 CSS（`variables.css`、`base.css`、`components.css`、`layout.css`、`utilities.css`）仍没有 `?v={{ version }}`，本次 `variables.css` 变化较大；生产强缓存下首次部署可能需要硬刷新。
- 主题偏好按浏览器/设备保存；同一浏览器换用户共享，清站点数据后回到跟随系统。
- 登录/注册/改密页没有切换控件，只遵循已存偏好和系统。
