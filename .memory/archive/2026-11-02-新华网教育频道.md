# 新华网教育频道接入（xinhua_edu）

- 日期：2026-11-02
- 合入：7069a74（worktree `worktree-xinhua-edu`，ff-only）
- 委托书式任务：4 频道（每日要闻/基础教育/高等教育/职业教育）接入每小时抓取，独立来源 `xinhua_edu`，默认关闭。

## 设计取舍

- 不新建 adapter 文件：教育频道与北京频道同属 news.cn 家族，canonical adapter 就一个（`http_xinhua.py`）；注册时除 `list_education_items` 外直接复用 `xinhua_*` 回调名。
- 教育列表解析独立成 `_parse_education_list_html`，不复用 `_parse_list_html`：教育条目第一个链接是图片（无文字），全页扫链接并在查标题前登记 URL 的旧解析会把整条丢掉；侧栏块也在容器外。
- 列表日期以 URL `YYYYMMDD` 为准、`.time` 兜底：真实页面两者双向错位 ±1 天（见预检）；详情精确时间抓到后覆盖，口径闭环。
- 失败分级按委托书表：单频道 HTTP 失败 / 容器缺失 → stderr `[warn]`（print，LOGGER.warning 在 worker 不可见）+ 其余频道照常；全部失败 → RuntimeError；解析出文章但窗口内 0 条 → 正常。
- `_ARTICLE_PATH_RE` 放宽为允许日期前一段**小写**栏目名（`(?:[a-z]+/)?`），slug 段用 `(?i:([0-9a-f]{32}))` 保持大小写不敏感且分组序号不变（group(1)=日期、group(2)=slug——第一版写成非捕获的 `(?i:[0-9a-f]{32})`，`group(2)` 直接 no such group，测试立刻抓住）。`_url_date` 同步放宽。
- 窗口 `XINHUA_EDU_LOOKBACK_DAYS` 独立于 `XINHUA_LOOKBACK_DAYS`，默认 3。

## 测试基建的一处必要修正（超出「各加一项」的字面范围，记录原因）

`tests/test_crawl_source_registry.py` 的 `_patch_linked_callbacks` 原来按回调名打桩、marker 用默认参数绑定。`xinhua` 与 `xinhua_edu` **共用** `xinhua_make_article_id` 等名字后，同名桩循环打两次只留最后一个来源的 marker，`xinhua` 用例必炸。修正：四个共用回调的桩 marker 改为**调用时从 item.url 的 host 推导**（`list_items` 名字各来源唯一，仍按名绑定）。这是「多来源共用回调」结构的必然要求，已在桩上方注释说明。

## 变异测试发现的夹具修正

M1（去掉 `#content-list` 圈定、全页扫 `.item`）第一版只被「连带删掉 raise」的容器缺失用例拦住，T2 没拦——因为侧栏噪音最初做成 `<li>`，全页扫 `.item` 根本扫不到。真实站点的侧栏模板会复用 `.item` 形态（委托书也预判了这种噪音），夹具里把侧栏噪音条目改成 `.item` 块后，M1 由 T2 拦住。教训：**变异「被拦住」要看是不是指定用例拦的，顺便暴露夹具噪音形态要贴真实风险**。

## 真实页面只读预检（2026-11-02，未写库）

1. **各频道解析**（默认窗口 今天-3）：每日要闻 3 / 基础教育 1 / 高等教育 4 / 职业教育 1，合并 unique=9；非文章链接每频道 15 条（每条目恰好一条微博分享链接）。高等教育近 30 天：首屏 15 条跨 2026-10-21→11-02 ≈ **1.2 条/天**（前期方案估 4 条/天系 4 频道合计口径，首屏实测合计 ≈3.2 条/天，方向一致）；内容构成约六成为院校宣传稿（耿丹学院/中华女子学院/戏曲学院/公安大学等），四成为会议与政策新闻。
2. **详情三形态**：`education.news.cn`、`www.news.cn`、`www.news.cn/legal/` 前缀三篇详情均被现有 `fetch_detail` 无改动解析成功（标题/精确到秒时间/正文/无图片语法）。
3. **跨频道同 slug**：教育 4 频道全页 76 个 slug 与北京频道 5 栏目（聚焦/科教/要闻/社会/京华新声）共 76+ 个 slug 交集为 **0**，未找到同 slug 稿件（同 ID 不重复入库的机制仍由 existing_ids 全表查重保证）。
4. **URL 日期 vs 详情时间**：两个错位样本方向相反——基础教育「北京一零一中」URL=20261016、列表显示 10-17、**详情时间 2026-10-17 08:00:00（跟显示日期）**；每日要闻「特色教育多元化」URL=20261025、列表显示 10-26、**详情时间 2026-10-25 15:16:52（跟 URL 日期）**。委托书的「URL 优先」口径维持不变；错位最多 ±1 天，由详情覆盖收口。
5. `ds_*.json` 翻页探测（`/gdjy/ds_1.json` 等）均 404，站方只在需要时生成；抓取按委托书不处理翻页。
