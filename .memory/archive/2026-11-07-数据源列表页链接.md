# 数据源页：无账号来源的「列表页」链接

- 日期：2026-11-07
- 合入：751d38a（worktree `worktree-sources-list-pages`，ff-only）
- 委托：系统设置 · 数据源页给无账号来源加「列表页」链接

## 需求与拍板

数据源页「每小时来源」中，不需要账号的来源（中新网、中新网新疆、中国教育报、
光明网、新华网北京、新华网教育、科技日报、北京商报）原来只显示灰色
「无需账号」。用户日常要打开原始列表页核对漏稿与改版，因此：

- 列表页地址必须就是爬虫本轮实际请求的页面，**只有一份来源**：后端直接从各
  adapter 的现有常量取值，不在 `SOURCE_CATALOG`、前端或别处另抄 URL。
- 单个列表页的来源：行内显示「↗ {label}」外链，文字完全取自后端 `label`，
  前端不做替换；无展开按钮。
- 多栏目的来源（新华网北京 15 个、新华网教育 4 个）：行内「共 N 个栏目」纯展示
  徽标 + 展开按钮，展开后是只读链接芯片（栏目名 + ↗），页面不能增删栏目。
- 栏目面板与账号面板共用 `state.expandedSource` 手风琴；启停来源重渲染后保持
  已展开状态。
- payload 缺 `list_pages` 或某来源列表为空（前后端未同时部署）时，该行退回
  「无需账号」，不报错、不影响其他行。

## 实现

### 接口

`GET /api/admin/settings` 的 `sources[]` 每项新增：

```json
"list_pages": [{"label": "列表页", "url": "https://..."}]
```

需要账号的来源与每日任务来源返回 `[]`；顺序与 adapter 常量一致。

实际片段（新华网北京）：

```json
{
  "key": "xinhua",
  "display_name": "新华网北京",
  "daily_only": false,
  "requires_accounts": false,
  "list_pages": [
    {"label": "新华社记者看北京", "url": "http://bj.news.cn/jz/index.htm"},
    {"label": "京华新声", "url": "http://bj.news.cn/jhxs/index.htm"},
    {"label": "聚焦", "url": "http://bj.news.cn/jj/index.htm"}
  ]
}
```

实际片段（光明网）：

```json
{
  "key": "gmw",
  "display_name": "光明网",
  "daily_only": false,
  "requires_accounts": false,
  "list_pages": [{"label": "列表页", "url": "https://news.gmw.cn/node_4108.htm"}]
}
```

### 映射落位：新建 `src/console/source_list_pages.py`

不在 `settings_service.py` 里堆 8 个来源的 if：映射只做「取地址 + 加栏目名」，
独立模块让「新增无账号来源忘了接列表页」这件事有一个明确的落点。映射每次调用
重新读 adapter 取值规则，不缓存环境变量。`settings_service` 负责
`requires_accounts or daily_only → []` 的兜底，避免映射模块知道页面语义。

### 环境变量规则放进 adapter

- `http_gmw.resolve_listing_url()`：`GMW_BASE_URL` 覆盖 `DEFAULT_LISTING_URL`，
  空白值按未设置处理（与原 `crawl_sources._env_str` 口径一致）；
  `crawl_sources._gmw_runner_kwargs` 改为调用它。
- `http_chinaeducationdaily.resolve_start_url()` + `resolve_listing_url()`：
  `JYB_START_URL` 覆盖 `SEARCH_URL`，设置页链接再加空的 `topsearch` 参数；
  `list_items` 改为调用 `resolve_start_url()`。

选择把规则收进 adapter，而不是在设置页侧按同样变量名读一遍：爬虫和页面各读一次
环境变量必然有一天漂移，而这次需求的核心就是「页面上看到的就是爬虫请求的」。
改动面只有取值规则一行，没有碰抓取/解析/翻页。

### 前端

`sources_tab.js`：

- `sourceListPages(source)` 对缺失/非数组返回 `[]`（F5 的兜底）。
- 单页：`a.source-list-page-link`，`target="_blank"`、`rel="noopener noreferrer"`、
  `aria-label="打开 {显示名} 的{label}"`。
- 多页：`span.source-column-count`（共 N 个栏目）+ 与账号面板同一个
  `.source-accounts-toggle`；`li.source-columns-panel[data-columns-for]` 作为来源行
  的兄弟节点常驻、靠 `hidden` 折叠。
- `syncSourcePanels()` 同时处理 `.source-accounts-panel` 与 `.source-columns-panel`，
  仍只读 `state.expandedSource`；重渲染时从 state 还原展开态。
- 栏目芯片直接渲染 `<a>`，不复用 `source_accounts.js` 的 `buildAccountChip`
  （那会把开关和删除一起带出来）。

CSS 在 `settings.css` 数据源页签段：栏目面板与账号面板共用底色/缩进/左侧色条；
栏目芯片沿用账号芯片的尺寸与圆角，但用虚线边框 + 常驻 ↗ 表示只读。

## 测试

### 新增后端 `tests/test_source_list_pages.py`

- B1：按 `SOURCE_CATALOG` 遍历，非每日且不要求账号的来源 `list_pages` 非空，
  其余为空数组（新增无账号来源却忘了接列表页会直接失败）。
- B2：`xinhua`/`xinhua_edu`/`stdaily`/`bbtnews` 与 adapter 常量逐项有序相等；
  字面量锚定 `jyb` 与 `chinanews` 地址。
- B3：`GMW_BASE_URL`、`JYB_START_URL`（含带 query 与不带 query 两种）跟随变化。
- B4：中新网 `_fetch_page_html(1/3)` 请求 URL 逐字不变。
- 另锁映射每次返回新对象、`jyb` 链接 = 爬虫起点 + `?topsearch=`。

### 前端 F1-F5

新增夹具 `sourcesWithListPages()`（保留 `defaultSources` 作为缺字段场景）；
新增 `columnsPanel` / `columnChips` 辅助。覆盖：

- F1 单页外链属性 + 无展开按钮/无「无需账号」；
- F1b 文字取自 label（滚动新闻/教育频道/列表页）与任意字符串原样显示；
- F2 15 个栏目顺序、href、只读（无 input/button/textarea、无刷新名称）；
- F3 与账号面板共用 `state.expandedSource`；
- F4 启停重渲染后栏目面板保持展开；
- F5 缺字段/空数组逐行兜底、无控制台错误。
