- **env 自动读取**：`src/config.py` 重构为 `_parse_env_files()`（纯解析，先读到的文件优先）+ `_apply_env_values()`（无空档应用：先整体覆盖文件来源变量、再只删文件里已不存在的变量）。`refresh_environment_if_changed()` 对 `_ENV_FILES` 三个文件做指纹（存在性 + mtime_ns + size），变化才 `reload_environment()`。检查挂在 `src/console/app.py` 的 `@app.middleware("http")` 一处。`reload_environment()` 保留（`reload_server_environment` 服务函数与 `POST /api/admin/settings/environment/reload` 路由删除）。
- **白名单追加语义**：`llm_allowed_hosts = DEFAULT + LLM_ALLOWED_HOSTS 追加`（去重、小写、默认在前）。默认列表 8 个域名：原 3 个 + `api.moonshot.cn`、`api.moonshot.ai`、`dashscope.aliyuncs.com`、`ark.cn-beijing.volces.com`、`api.siliconflow.cn`（已对照各家官方文档核对，2026-11-07）。

- **按步骤实测**：8 个步骤 adapter 各新增 `probe_request_extras(endpoint)` 返回真实请求里 model/messages/max_tokens 之外的固定参数（只有 `llm_beijing_gate` 带 `response_format`，经 `build_response_format`；`llm_summary` temperature=0.2，其余 0）。探针 `_probe_model` 新增 `step` 参数，`payload.update(extras)` 后照常 `finalize_payload`；extras 含 `response_format` 时探针消息换成 `'连通性测试：请只回复 JSON {"ok": true}'`（JSON 模式要求提示里有 JSON 字样）。接入点级实测（新增/默认模型变更的接入点）不传 step。

## 经验

1. **变异要打在行为真正被观察的实现点上**：K6 第一版打在 `endpointWillBeTested` 的 `item.isNew ||` 上存活了——新接入点本来就会被后面的 `!savedItem` 兜底判 true，属等价变异；改成打在保存拦截的 blocking 赋值上（行为语义本身）立即被 E20 击杀。冗余分支会让「删除某行为」类变异失效。
2. **同一表达式可能在生产与探针各出现一次**：`"response_format": build_response_format(endpoint)` 在 `call_beijing_gate` 和 `probe_request_extras` 里逐字节相同，变异定位必须带 `return {` 上下文；S2 靠「monkeypatch build_response_format → 探针跟随」证明复用。
3. **jsdom「分区值 vs 顶层负载」**：`host_allowed` / `configured_api_key_envs` 在顶层 `endpoints` 负载，只读列表和步骤行却读 `savedEndpointsValue()`（分区值）——第一次实现就栽在这里（E24/E25 标红不生效）。读「展示字段」一律走 `endpointsPayloadInfo()`。
4. **合并冲突的高效解法**：双方改同一条巨型 bullet 的不同片段时，`git show` 取三方版本 + `difflib.SequenceMatcher` 定位对方改动区间，确认不相交后「以对方版本为基础 + 自己的片段替换」，比重打字快且不丢内容。
