## 代码修复：额外参数只留一份定义

`probe_request_extras` 改名 `request_extras`（函数已不只服务探针）。8 个 adapter 的真实请求改为用它拼请求体：

- `llm_summary` / `llm_source`：`payload.update({"model": model, **request_extras(endpoint)})`
- `llm_scoring` / `sentiment_classifier` / `external_filter_model` / `llm_duplicate_review` / `llm_prompt_optimizer`：payload 字面量末尾 `"temperature": 0.0` 一行替换为 `**request_extras(endpoint)`
- `llm_beijing_gate`：payload 字面量的 `"temperature": 0` + `"response_format": build_response_format(endpoint)` 两行替换为 `**request_extras(endpoint)`

键序保持原样（model → messages → temperature → response_format），`requests.post(json=payload)` 序列化字节不变，现有「逐字节复现旧请求」类测试（如 test_llm_endpoint.py 的 expected_payload 对照）全部继续通过。函数 docstring 改为「真实请求与保存实测都用本函数的返回值拼请求体——额外参数只有这一份定义」；`settings_service` 的映射改名 `_STEP_REQUEST_EXTRAS`；`docs/data_flow.md` 同步函数名与「只有一份定义」表述。

## 补的测试

1. **探针与真实请求一致**（`test_step_probe_payload_matches_real_request_payload`，参数化 9 例 = 8 步骤 + beijing_gate×deepseek）：真实路径调各 adapter 入口函数（`business_config_context(make_endpoint_config(...))` 冻结业务配置避免碰库）、探针路径调 `test_llm_model`（假 adapter 提供同一份接入点定义），各自只替换最底下 `post_chat_completion` 捕获请求体；断言除 `model`/`messages`/`max_tokens` 外字段完全相同。桩响应按步骤给能通过各自校验/解析的内容（sentiment 给 JSON、beijing_gate 给决策 JSON、duplicate_review 给 `{"duplicate_groups":[]}`、prompt_optimizer 给 `{"decision":"no_change"}`）。
2. **中间件接线**（`test_console_requests_refresh_env_files_automatically`，test_settings_page.py）：`create_app()` + TestClient + monkeypatch `_ENV_FILES` 指向临时文件并复位 `_ENV_LOADED`/`_ENV_FILE_KEYS`/`_ENV_FILES_SIGNATURE`；第一个请求（GET /admin/settings 页面，不碰库）完成初始读取；改写文件补 `MW_PROBE_TEST_API_KEY`；第二个请求 GET /api/admin/settings（假 adapter）断言 `configured_api_key_envs` 反映新状态。finally 清理 os.environ 污染 + 清 get_settings 缓存（自动重读会绕过 monkeypatch 直接写 os.environ，不留神会污染后续测试）。
3. **跟随默认也算在用**（`test_load_business_config_fails_when_default_endpoint_blocked_for_follow_steps`，test_business_config.py）：收紧白名单让 default=openrouter 不在其中，`_settings_rows()` 多步 endpoint=null → `load_business_config` 必须失败且报错写出「摘要生成」。autouse `_allowed_hosts` 夹具 patch 同一属性，测试内再 patch 一次（后 patch 胜出，teardown 逆序还原）。
4. **JSON 探针消息**（`test_probe_message_switches_to_json_only_for_response_format_steps`）：beijing_gate 实测消息含 JSON 字样且 ≠「只回复 OK」，summary 实测消息仍是「只回复 OK」。
