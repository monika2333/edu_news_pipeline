## 需求

用户给出数据源入口 `https://bjrbdzb.bjd.com.cn/bjwb/paperindex.htm`，要求「按照前面的规则」把北京晚报电子版接入。前面的规则指 2026-11-14 的电子报合并方案：只写适配器 + `SOURCE_CATALOG` 一行 + 设置页开关，不新增启动脚本 / 注册脚本 / 计划任务；电子报任务只做抓取；新来源默认不启用。

## 站点实测（2026-11-14）

- `paperindex.htm` 是 200 的纯 JS 跳转页：`window.location.href="./mobile/2026/20261114/20261114_m.html?v="+new Date().valueOf();`，指向**当前最新一期**；`Last-Modified` 随一期上传更新（当天 04:44 UTC）。
- 刊期页 `mobile/YYYY/YYYYMMDD/YYYYMMDD_m.html`：当天 46 条、16 个版面；未出刊日期（20261115、20261201）返回 **404**；`period/YYYYMM/period.js` 也存在，但 `datelist` 顺序不是日期序（`20261101,20261103,20261102,…`），当月未出刊 404。
- 正文页结构、`data-newid` 形态（`bjwb2026111400101`）、`#main-title`/`#sub-title`/`#guide`/`#date`/`#content` 选择器与北京日报完全一致 —— 直接把 bjrb 的解析器用 `source_key` / `source_name` 参数复用。
- **正文图片一律 `data-src` 懒加载、没有 `src`**（当天 46 篇里所有 `<img>` 都是 data-src），而 bjrb 的 `_render_image` 只读 `src`，所以晚报正文图片不会进 `content_markdown`（正好符合「图片一律剥离」口径，没有为它加 data-src 渲染）。
- 当天 46 条里有 **5 条纯图片版面**：`结婚启事`、`■广告`、`电视节目预告`、`找不同答案`、`一步棋答案`，`#content` 只有一个 `data-src` 图；按 bjrb 的严格解析会抛 `Empty … content`。

## 设计

- 来源 key `bjwb`、别名 `beijingwanbao`、显示名「北京晚报」、`epaper=True`；稿件 `source` 固定「北京晚报」；`article_id` 前缀 `bjwb:`（形如 `bjwb:bjwb2026111400101`，与 bjrb 的双前缀同构）。
- **抓「站点当前最新一期」而不是「今天这一期」**（`paperindex.htm` 跳转 → 绝对地址 → 去掉 `?v=` 缓存参数 → 从 `/mobile/YYYY/YYYYMMDD/YYYYMMDD_m.html` 解析日期）。理由：晚报当天的版通常下午才上线，按当天日期会让 00:00/08:00/12:00 三轮反复抓空，也兜不住 23:30 之后才上传的尾单；跟随刊期索引则每轮都在检查「最新一期」，靠 `article_id` 幂等去重。`BJWB_DATE` 只用于历史补抓。
- 与 bjrb 同一平台的复用方式：`http_bjwb` 复用 `http_bjrb` 的 `parse_issue_index` / `parse_article` / `fetch_article` / 行构造函数，为此给 bjrb 侧加了向后兼容的 keyword 参数 `source_key`、`source_name`、`allow_empty_content`（默认值保持 bjrb 原行为，bjrb 测试全绿）。会话与取文 helper（`_create_session` / `_fetch_text`）直接借用，避免两份实现漂移。
- **纯图片版不算失败**：`http_bjwb.fetch_article` 传 `allow_empty_content=True`，正文留空写入 `raw_articles`（`detail_fetched_at` 照写），不计数失败、不进关键词闸门。`#content` 整个缺失、5xx、网络错误、刊期页 200 却解析不出稿件仍按真实故障抛出。
- 刊期未上线用 `BjwbIssueNotPublished`：`_run_bjwb_flow` 在流程层捕获后 `log_info` 一行、返回空 stats，不进 `failed_sources`。
- Flow 配置与 bjrb 完全一致（`load_existing_ids=False`、`count_prepare_errors=True`、`missing_ids_fallback="all"`、`detail_delay=BJWB_DELAY`）：两阶段抓取，失败详情下一轮会重试。
- 环境变量：`BJWB_DATE`、`BJWB_TIMEOUT`（默认 20）、`BJWB_DELAY`（默认 0.2）、`BJWB_BASE_URL`（默认 `https://bjrbdzb.bjd.com.cn/bjwb`），登记进 `docs/env_reference.md`。
