# 2026-11-04 来源别名卡片改单列布局

## 背景

「设置 → 高级 → 来源别名」原先把三个字段放进 `1fr 2fr` 两栏网格：后缀在窄栏、别名在宽栏，第三个字段「回退来源」按网格自动排位掉到**左窄栏**、别名下方留出一大片空白。回退来源的说明文字在窄栏里折成三行，和宽栏输入框高度对不齐，整体看起来像排版错位。用户反馈「排版实在有点乱」，并倾向直接单列。

同时用户明确：**不用**把来源别名单独拎成一栏或独立页面，仍留在高级页签里。

## 取舍

- **单列而不是重排两栏**：三种规则作用于同一串名称，纵向顺序天然对应处理先后；横排无论怎么分配宽度，第三个字段都会破坏左右等高。
- **加 1/2/3 顺序徽标**：归一化顺序是真实语义（先剥后缀 → 再替换别名 → 再检查回退名单），编号让单列不只是「把三块竖着摞起来」，也解释了为什么后缀列表的上下顺序有意义。徽标 `aria-hidden`，不进入无障碍名称。
- **字段间用细分隔线**：三个编辑器都带芯片框，没有分隔线时边界靠留白区分，长说明折行后会糊在一起。分割线颜色沿用保存栏的 `#eef2f7`。
- **补全说明文案**：原说明只讲格式（「按第一个等号拆分」），没讲字段在做什么。改为「定义 + 格式」两段；回退说明补上「归一化前后的名称都参与比对」，与 `matches_fallback_name` 的实际口径一致。
- **不做独立页签/入口**：用户拍板否决。来源别名低频，放进高级页签后已有页头说明与保存栏，单独开页只会多一层导航。

## 实现

- `advanced_tab.js`：`buildSettingsTextarea` 新增 `options.order`，在字段标题前渲染 `.advanced-field-step` 徽标；三个字段分别传 1/2/3，并更新 `hint` 文案。
- `settings.css`：`.advanced-alias-fields` 从 grid 改为 flex 单列；`> .advanced-field` 加 `padding: 18px 0` + `border-top`，首尾去边；新增 `.advanced-field-step` 徽标样式。删除 `≤600px` 里已经无意义的 `grid-template-columns` 覆盖。
- 未改动：字段顺序（后缀仍使 `.settings-textarea` 首个）、`.advanced-field` / `.alias-*` / `.keyword-*` 类名、textarea 唯一数据源的读写链路、保存与版本逻辑。
