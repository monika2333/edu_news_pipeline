## 需求

《北京日报》（bjrb）、《劳动午报》（ldwb）、《中国教师报》（zgjsb）原先各有一份启动脚本、一份注册脚本、服务器上三个计划任务，三份只差 `--sources`。改成：

1. 所有电子报只用一个 `EduNews_Epapers` 计划任务，每天 08:00、12:00、16:00、20:00、00:00 各跑一轮，抓已启用的电子报；
2. 电子报任务**只做抓取**（评分/摘要等由每 15 分钟的主流水线接手）；
3. 启停由设置页「电子报」分组开关管理（`app_settings.epaper_sources`，允许全部关闭）；
4. 以后新增电子报只需要适配器 + `SOURCE_CATALOG` 一行 + 开关，不新增脚本/计划任务。

## 站点实测：北京日报「刊期不存在」（2026-11-14）

请求明天（`20261115`）与下月（`20261201`）的真实返回：

| 请求 | 结果 |
|---|---|
| `GET /bjrb/period/202611/period.js`（当月，已出刊到 11-14） | 200，`datelist` 为 20261101…20261114，**不含 20261115** |
| `GET /bjrb/period/202612/period.js`（当月还没有任何一期） | **404**（`text/html`） |
| `GET /bjrb/mobile/2026/20261115/20261115_m.html`（未出刊日期） | **404** |
| `GET /bjrb/mobile/2026/20261114/20261114_m.html`（已出刊） | 200（17206 bytes） |

据此的判定口径（`BjrbIssueNotPublished`）：

- 月份索引 404、日期不在索引里、或索引已列出但刊期页 404 → **尚未上线**：流程层 `log_info` 一行「北京日报 YYYYMMDD 期尚未上线」后跳过该来源，`stats` 全 0、**不进 `failed_sources`**；
- 5xx、超时/网络错误、刊期页 200 却解析不出稿件 → **真实故障**，异常照旧抛出，由 `run()` 记进 `failed_sources`。

关键点：**不能把 `requests.RequestException` 一律折成「尚未上线」**（原实现的 `_issue_date_available` 就是这么干的，会把站点 5xx 永久吞掉）。改造前当天没出刊其实也只返回空列表、不会计入失败，所以这次主要是把「尚未上线」显式化（有日志、可测试）并堵上「5xx 被当成未上线」的洞。

## 设计

### 配置分区 `epaper_sources`

- `business_config.py`：`SETTING_SECTIONS` 增加 `epaper_sources`；`SourceDefinition.daily_only` 改名 `epaper`；`normalize_source_list(..., allow_epaper=...)`；新增 `validate_epaper_sources`（只接受电子报来源、按 `SOURCE_CATALOG` 目录序、**允许空数组**）；`BusinessConfig.epaper_sources` + `snapshot()["epaper_sources"]`；`load_business_config` 缺失该分区即 `BusinessConfigError`（与其它分区一致）。
- `crawl_sources` 继续拒绝电子报来源（文案改为「是电子报来源，只能由电子报任务抓取，不能加入每小时来源」）。
- 与 `crawl_sources` 各有独立 version：设置页两个开关各自带自己的 version，互不触发乐观锁冲突。

### 流水线步骤 `crawl-epapers`

`scripts/run_pipeline_once.py` 的 `STEP_REGISTRY` 新增 `crawl-epapers`（**不进** `DEFAULT_PIPELINE`）：

```python
sources = list(get_business_config().epaper_sources)
if not sources:
    print("[pipeline] 无启用的电子报，跳过 crawl-epapers", file=sys.stderr)
    return {}
failed = run_crawl(sources=sources)
return {"crawl_failed_sources": ",".join(failed)} if failed else {}
```

**空列表必须在这里拦住**：`run_crawl(sources=[])` 会被 `normalize_source_list` 判「不能为空」，`sources=None` 会退回每小时来源——两种都是错的。

### bjrb 适配器 / 流程层

- `http_bjrb.py`：新增 `BjrbIssueNotPublished`；`_issue_date_available` 只把 404 与「不在索引」当未上线，其余异常抛出；`list_issue_items` 对未出刊抛该异常、刊期页 404 也换算未上线、已出刊但解析 0 条抛 `RuntimeError`（站点结构变化属真实故障）；删除已无用的 `LOGGER`。
- `crawl_sources.py` 的 `_run_bjrb_flow`（只改这一个 flow + 两个 import）：先直接调 `bjrb_list_issue_items`，捕 `BjrbIssueNotPublished` → `log_info` + 返回空 stats；其余异常任其抛出（`run()` 记 `failed_sources`）。拿到 items 后交给 `_run_source_flow`（`list_items` 用闭包返回预取结果，避免重复请求）。
- 劳动午报 / 中国教师报抓「站点当前最新一期」，不需要改。

### 脚本

- 新增 `scripts/run_epapers.ps1`（照 `run_bjrb_daily.ps1`：单锁 `locks/pipeline_epapers.lock`、日志 `logs/pipeline_epapers_<ts>.log`、`--steps crawl-epapers --trigger-source scheduler-epapers`）。
- 新增 `scripts/tasks/register-epapers.ps1`（默认 `08:00, 12:00, 16:00, 20:00, 00:00`，任务名 `EduNews_Epapers`，`MultipleInstances IgnoreNew`、2 小时上限）。
- 删除 6 份旧脚本。两份新脚本纯 ASCII（`tests/test_powershell_script_encoding.py` 覆盖）。

### 设置页

- 「每日任务」只读分组改成「电子报」带开关分组：`SOURCE_TOGGLE_GROUPS` 参数化 `toggleSourceEnabled`（分区名 / 组内过滤 / 是否允许清空 / 拦截文案），行结构与每小时来源一致（`#sources-epaper-list`），卡片带「最近修改」行；`epaper_sources` 分区缺失时整张卡片不渲染（不能用 `renderImportNotice`，它会清空整个面板）。
- 电子报不做「至少保留一个」拦截；失败回滚 + 行内错误、409 给「载入最新配置」，与每小时来源一致。
