## jsdom 夹具约定（duty_summary_harness.js）

- waitFor/assertNever 对齐 AGENTS.md 测试节约定（waitFor 超时即抛错；否定断言用 assertNever）。
- 夹具班次日期口径仿 generate_shifts：ends_at=边界时刻（夹具取 05:00+08:00）而非午夜——正好午夜的日期键会滚到下一天导致 chooseInitialShift 选不中。
- 静态夹具视觉验证法：渲染真实路由页面 + 注入 fetch 桩 + http.server（translate_path 必须剥 `?v=` query 否则静态资源 404）；浏览器按 URL 缓存，改 CSS 后要重新生成夹具换 `?v=` 才生效。
